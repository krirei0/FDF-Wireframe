# FDF Wireframe

A 3D wireframe renderer written in C++ using SDL2.

<img width="1594" height="927" alt="42_map_scrshot" src="https://github.com/user-attachments/assets/eb93fb54-a128-49dc-8b52-99676fb39409" />


## Features

- FDF map parsing
- Isometric projection
- 3D to 2D coordinate transformation
- Scaling and centering
- Height-based coloring
- SDL2 rendering
